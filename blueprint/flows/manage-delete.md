# Flow: Manage & delete

## Entry

Settings → **Manage Drive Entries**.

## Steps

1. Tabs: Trips | Tickets
2. List all entries of that type (no period filter on this screen)
3. Tap row → Edit
4. Swipe row end-to-start → confirm dialog
5. Confirm Delete → DeleteDrive(id) → cancel alarm → snackbar → list refresh
6. Cancel dialog → row remains

## Notes

Swipe-delete is on Manage Entries (and documented in onboarding). Main Schedule currently uses tap-to-edit only.
