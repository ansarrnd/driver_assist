# Flow: Themes

## Entry

Settings → **App Theme**.

## Steps

1. Show chips for all 10 ThemeIds
2. Highlight current selection
3. Tap chip → ChangeTheme → persist → app chrome updates (nav, buttons, gradients)

## Persistence

Secure key-value: `selected_theme` = theme id string (e.g. `csk`).

## Default

`rcb` when missing/invalid.
