# Product jobs

## Primary user

Professional / semi-professional drivers managing pickups and ticketed transfers.

## Jobs to be done

1. **See what's ahead** — view trips/tickets filtered by today, this week, or this month
2. **Capture a booking quickly** — add customer, places, datetime, reminder
3. **Correct mistakes** — edit an existing entry
4. **Clean history** — delete entries with confirmation
5. **Never miss a pickup** — alarm at a chosen offset before datetime
6. **Personalize** — pick an IPL team theme that persists across launches
7. **Learn the app once** — short onboarding on first launch

## Non-goals (current product)

- Multi-user auth / accounts
- Live maps / navigation
- Payments
- Cloud sync conflict UI
- Push from server (alarms are device-local)
